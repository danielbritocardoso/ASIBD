Administracao de Sistemas Informaticos e Base Dados

O Curso de Administracao de Sistemas Informaticos e Base de Dados forma tecnicos versateis com competencias em redes, servidores, bases de dados e seguranca. A formacao inclui tambem programacao, analise e modelacao de sistemas, desenvolvimento web e criacao de APIs, alem de tecnicas de monitorizacao de sistemas informaticos. Os alunos sao preparados para resolver problemas reais e integrar equipas tecnicas em empresas ou instituicoes publicas, com uma base solida para continuar estudos superiores na area de tecnologia.
